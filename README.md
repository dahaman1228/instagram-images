# instagram-images

Instagram 投稿用の画像を置くリポジトリです。GitHub Pages で公開し、`https://dahaman1228.github.io/instagram-images/images/<ファイル名>` の URL から取得します。

- 画像は JPEG（Instagram API の要件）
- 生成: ComfyUI + Qwen Image 2.1 Turbo（ローカル）

## 生成ログ

- `images/recruit-01.jpg`: ComfyUI 0.39.2 + Qwen Image 2.1 Turbo（bf16）、seed 42、1328x1328、8 ステップ
- プロンプト: バスケットボールのコートでの練習風景（文字・ロゴなし）
